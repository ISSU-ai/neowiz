# ChatGPT · Claude 통합 AI 사용자 교육

`index.html`은 네오위즈·메가존클라우드 로고와 발표자료/실습 버튼이 있는 메인 페이지입니다. 실습은 `guide.html`에 있으며, 실습 파일 자체는 서버·설치·API 키 없이 단독으로 열 수 있습니다. 메인을 포함해 웹에 배포하려면 아래 ZIP 또는 `dist/`의 전체 파일을 사용합니다.

주제 1는 **이론·강사 시연 20분 + 핸즈온 40분**입니다. 선택 주제 2는 별도 40분이며 주제 1 시간표에 포함하지 않습니다. Google 계정 연결과 외부 작업은 ChatGPT 또는 Claude 안에서 진행합니다. 이 사이트는 계정·메일·캘린더를 직접 조회하거나 변경하지 않습니다.

## 파일

- `index.html`: 네오위즈 교육 메인 · Canva 발표자료/실습 선택
- `guide.html`: 오프라인 사용 가능한 수강생용 가이드와 강사용 모드
- `assets/`: 실제 네오위즈·메가존클라우드 로고
- `dist/`: 정적 웹 배포 파일
- `neowiz-ai-training.zip`: 웹 배포용 압축 파일
- `scripts/package-site.py`: 배포본 생성 스크립트
- `instructor-email.txt`: 사전 발송용 제목·본문. 실제 발송은 강사가 수행
- `QA.md`: 검증 결과, 원본 분석, 확인하지 못한 환경 의존 사항
- `instructor-brief.md`: 강사용 한 장 진행 요약
- `previews/`: 데스크톱·모바일·프롬프트·Gmail·Calendar 화면
- `tests/qa.cjs`: Chrome / Playwright 기반 회귀 검사. 수강생 실행에는 불필요

## 교육 전 준비

1. 참가자 약 30명의 사용 제품·요금제·회사 계정·조직 연결 정책을 확인합니다. 강사 시연과 다른 권한의 참가자가 있을 수 있습니다.
2. 승인된 실습용 Google 계정과 Calendar를 준비합니다. 읽기와 쓰기를 따로 확인합니다. 회사 정책을 우회하거나 인증 정보를 공유하지 않습니다.
3. `instructor-email.txt`의 가상 회의록을 사전 발송하고 수신 여부를 확인합니다. 수신자 주소가 불필요하게 노출되지 않는 조직의 발송 방식을 사용합니다.
4. 강사 계정으로 정확한 제목의 메일 검색 → 분석 → 초안 → 승인 → 일정 생성 → 재조회를 리허설합니다. 이미 생성된 실습 이벤트가 있으면 중복 생성하지 않습니다.
5. 기본은 게스트 없는 개인 일정입니다. 초대 실습이 필요하면 사전에 수신에 동의한 교육용 계정만 사용합니다. 가상 인물 이름으로 실제 연락처를 찾지 않습니다.
6. 참가자에게 HTML을 미리 배포하고 Chrome·Edge·Safari 등 최신 브라우저로 열도록 안내합니다. 브라우저·회사 정책상 로컬 파일 실행이 막히면 승인된 정적 웹 호스팅을 이용합니다.
7. 강사용 모드는 숨김 기능일 뿐 보안 기능이 아닙니다. 배포본에는 개인 정보·계정 비밀번호·토큰을 넣지 않습니다.

## 실행과 조작

전체 보기·강사용 모드·인쇄·진행 초기화는 페이지 하단의 “설정”에서 사용할 수 있습니다.

- 주제 1 / 주제 2를 선택합니다. 체크와 진행률은 과정별로 분리됩니다.
- ChatGPT / Claude / 모두 보기로 제품별 연결 안내를 전환합니다.
- 왼쪽 목차 또는 이전·다음 버튼으로 이동합니다. 모바일 목차는 가로로 스크롤할 수 있습니다.
- 기본 화면은 Learning Path의 단계별 페이지입니다. 목차·이전/다음으로 해당 단계만 열며, 각 단계의 URL(`#search`, `#analyze` 등)을 공유하거나 새로고침해도 같은 페이지로 돌아옵니다. 브라우저 뒤로/앞으로 가기를 지원합니다. 전체 보기로 한 번에 펼치고 집중 모드로 다시 돌아올 수 있습니다.
- 프롬프트 전체 복사 → 본인이 사용하는 AI 제품에 직접 붙여넣습니다.
- 복사 권한이 막히면 기존 복사 방식으로 재시도하고, 실패하면 수동 선택 창을 제공합니다.
- 완료 체크는 브라우저 localStorage에 저장됩니다. 저장이 차단되어도 현재 세션에서는 동작합니다. `file://`의 저장 범위는 브라우저별로 다르므로 파일 위치·이름·브라우저를 바꾸면 복원되지 않을 수 있습니다.
- 진행 초기화는 현재 과정의 체크만 지웁니다. 다른 과정은 유지됩니다.
- 초대용 이메일은 메모리에서만 사용합니다. 저장·로그·외부 전송하지 않으며, 복사한 내용을 AI에 붙여넣는 시점에는 해당 제품에 전달됩니다. 인쇄할 때는 입력 주소를 제외합니다.
- 인쇄는 두 과정·양쪽 제품 안내·접힌 참고 내용·강사용 자료까지 포함하는 전체 핸드북입니다. 과정별 축약 인쇄는 지원하지 않습니다.

## 연결이 제한되면

- Gmail 검색 실패: 원본을 직접 복사하거나 내장 가상 메일을 AI에 제공합니다. 직접 검색한 것으로 표시하지 않습니다.
- Calendar 쓰기 불가: 작성 링크를 열어 대상 계정·시간·초대·중복을 확인한 뒤 직접 저장합니다. 링크만 열면 생성되지 않습니다. Google이 자동 추가한 Meet·알림 설정도 확인합니다.
- Calendar 재조회 불가: Calendar 원본에서 직접 확인합니다. 권한 오류·조회 실패와 실제 미등록을 구분합니다.
- 외부 서비스 전체 차단: 원문·분석·일정 초안·검증 방법까지 연습하고 실제 등록/조회 체크는 미완료로 남깁니다. 전체 완료를 허위로 기록하지 않습니다.
- 진행 지연: 연결 문제에 2분 이상 머무르지 말고 대체 경로로 전환합니다. 분석 문장 다듬기는 생략할 수 있지만 마지막 5분의 실제 결과 검증은 확보합니다.

## 주제 2 · 바탕화면 자료 → Drive 요약본

사이트에서 ZIP을 다운로드하고 압축을 푼 뒤, 바탕화면의 `AI_실습_주제2` 폴더에 다음 3개 파일을 넣습니다.

- `01_고객문의.txt`: 가상 문의 5개
- `02_서비스안내서.txt`: 기능·요금·체험·지원·설치 기준
- `03_FAQ.txt`: 질문별 추가 근거와 미확인 사항

다운로드는 브라우저의 저장 위치 설정을 따릅니다. 사이트가 바탕화면 폴더를 자동 생성하거나 사용자 파일을 직접 읽지는 않습니다. ZIP·개별 파일은 HTML에 내장된 데이터로 브라우저에서 생성되며 오프라인에서도 내려받을 수 있습니다. 모두 UTF-8 텍스트이고 실제 기업 정보가 아닙니다.

| 단계 | 강사 진행 예산 | 완료 결과 |
|---|---:|---|
| 다운로드·폴더 준비 | 7분 | 바탕화면의 지정 폴더에 파일 3개 |
| 폴더 파일 읽기 | 7분 | 실제 읽은 파일명·식별자·내용 확인 |
| 요약본 작성 | 10분 | 출처 항목이 있는 요약 초안 |
| 원문 대조 | 6분 | 검토를 마친 최종 내용 |
| 승인 후 Drive 저장 | 7분 | 승인한 대상 폴더에 요약본 파일 |
| 저장 결과 확인 | 3분 | 실제 파일·본문·공유·중복 확인 |
| 합계 | 40분 | 주제 1의 60분과 별도 |

데스크톱의 Work/Cowork에서 폴더 접근 기능이 제공되고 사용자가 권한을 준 경우에만 실습 폴더를 읽게 합니다. 폴더 이름을 말하는 것만으로 권한이 생기지 않습니다. 웹·일반 Chat·클라우드 실행·폴더 접근 제한 환경에서는 파일 3개를 대화에 첨부해 같은 과정을 진행합니다. 첨부마저 막히면 내장 원문 직접 제공 경로로 분석하되 실제 폴더를 조회한 것으로 기록하지 않습니다.

최종 파일명은 `고객문의_검토요약.txt`입니다. 바탕화면 폴더와 Google Drive 폴더는 별개입니다. 실제 Drive 계정·대상 폴더·형식·내용·기존 권한·중복을 확인한 뒤 별도로 승인합니다. 기존 파일 수정·덮어쓰기·삭제나 신규 공유는 하지 않습니다. Google Docs 등 다른 형식으로 만들 경우 실제 지원 도구와 새 이름을 먼저 확인합니다.

AI의 Drive 쓰기가 제한되면 AI에서 최종 요약 파일을 다운로드하고 Google Drive에 직접 업로드합니다. 파일 생성 기능도 없으면 최종 요약을 일반 텍스트 편집기에 붙여넣어 UTF-8로 저장한 뒤 업로드합니다. 직접 업로드도 동일 이름이 있으면 덮어쓰기를 취소하고 다른 이름을 선택합니다. Drive 전체가 막히면 로컬 파일까지만 완료하고 실제 저장·조회는 미완료로 남깁니다.

강사는 사전 Gmail 발송이나 Drive 원본 문서 배포 없이 이 주제를 준비할 수 있습니다. 다만 AI 파일 읽기·Drive 쓰기 권한과 회사의 다운로드·업로드 정책을 사전 확인하고, 초급자 리허설로 실제 40분 운영 가능 여부를 확인하세요. 바탕화면 전체나 개인 폴더를 공유하지 않습니다.

## 다른 교육에 재사용

`guide.html`의 `course-data` JSON 한곳에서 교육명·교육 일자·회의 일시·담당 업무·차기 회의·시간대·초대 안내를 수정합니다. 날짜는 `YYYY-MM-DD`, 시간은 `HH:mm`입니다. 원문 메일·프롬프트·예상 정답·검토 정보·Calendar 작성 링크는 이 값에서 생성됩니다.

- 기본 가상 날짜는 2026-12-01 회의 / 2026-12-04 차기 회의입니다. 교육 당일 날짜로 자동 변경되지 않습니다.
- 교육명·교육 일자는 강사용 모드의 시작 화면에 표시됩니다. `trainingDate`의 기본값은 강사 지정입니다.
- 담당 업무는 `tasks`, 참석자와 역할은 `people`, 미확정 내용은 `unconfirmed`에서 관리합니다. 이번 교육 구조는 업무 두 건입니다. 업무 건수·시나리오 자체를 바꾸면 해당 설명·체크 문구도 검토해야 합니다.
- 날짜·시간·시간대를 바꾸면 Calendar 작성 링크는 그 지역의 시각과 `ctz`로 생성됩니다. 재사용 전 요일·시간대와 Google 작성 화면을 확인합니다.
- 수정 후 강사용 모드의 “제목과 본문”을 복사해 `instructor-email.txt`를 갱신합니다. 개발 환경에서는 아래 `--export-email` 옵션으로 동일하게 내보낼 수 있습니다.

## 검증 다시 실행

Node.js, 최신 Chrome과 Playwright가 있는 개발 환경에서만 필요합니다. 수강생은 설치할 필요가 없습니다.

```sh
npm install --prefix /tmp/neowiz-qa playwright @axe-core/playwright
NODE_PATH=/tmp/neowiz-qa/node_modules node tests/qa.cjs
```

실습 공통 데이터 수정 후 메일 파일도 다시 생성하려면:

```sh
NODE_PATH=/tmp/neowiz-qa/node_modules node tests/qa.cjs --export-email
```

공식 안내 확인일은 2026-11-24입니다. 제품 UI·요금제·조직 정책은 바뀔 수 있으므로 교육 직전에 사이트의 공식 링크로 다시 확인합니다. 실제 OAuth·검색·쓰기·초대는 이 정적 가이드의 테스트 범위 밖이며 강사 교육용 계정 리허설이 필요합니다.

## 핸즈온 적합성과 40분 소요 검토

현재 시나리오는 초급자에게 적절합니다. 가상 메일 한 건으로 범위를 제한하고, 분석 → 승인 → 외부 실행 → 검증을 끝까지 경험할 수 있습니다. 다만 담당 업무 두 건이 있는 짧은 메일이므로 복사·실행만 하면 깊이 있는 프롬프트 설계 학습은 제한됩니다. 원문 근거를 찾고, 부족한 답변을 확인·수정하며, 자신이 지시 조건 하나를 설명하도록 운영합니다.

다음 시간 범위는 실제 수강생 측정값이 아니라 현재 과제량을 기준으로 한 운영 추정입니다.

| 조건 | 예상 | 판단 |
|---|---|---|
| 연결 완료·도구에 익숙함·복사와 실행 중심 | 약 15~25분 | 40분을 보장하는 과제량은 아님. 검증·조건 수정 연습 포함 |
| 초급자·강사 동시 진행·원문 대조와 수정 포함 | 약 35~45분 | 40분 운영 권장안 |
| 신규 인증·관리자 승인·계정 혼선 다수 | 45분 이상 가능 | 연결을 사전 확인하고 2분 내 대체 경로 결정 |

| 단계 | 배정 | 수강생의 실제 활동 |
|---|---|---|
| 메일 조회 | 7분 | 계정 1 + 조회/경로 결정 2 + 원문 대조 3 + 선택·체크 1 |
| 회의록 분석 | 12분 | 간단·구체 요청 비교 2 + 지시서 확인·실행·응답 읽기 3 + 원문 대조 4 + 재검토/수정 2 + 공유 1 |
| 등록 정보 검토 | 7분 | 초안 요청 2 + 원문 기준과 비교 3 + 캘린더·게스트 결정 2 |
| 승인 후 등록 | 9분 | 중복·준비 3 + 초안 확인 2 + 별도 승인·실행 3 + 전환/정리 1 |
| 실제 결과 검증 | 5분 | 재조회 2 + Calendar 원본 확인 2 + 체크·회고 1 |
| 합계 | 40분 | 응답 대기와 화면 전환을 각 활동 시간에 포함 |

사전에는 실제 교육 환경과 비슷한 초급자 3~5명으로 리허설하고, 단계별 완료 시각과 막힌 이유를 기록해 조정하는 것이 좋습니다. 현재는 30명 대상 실측 검증을 마친 상태가 아닙니다. 첫 5분 연결 시연은 전체 참가자의 최초 인증을 해결하는 시간으로 가정하지 않습니다.

프롬프트는 각 실습의 “프롬프트 복사” 버튼으로 가져가 선택한 ChatGPT/Claude 입력창에 Ctrl+V 또는 ⌘V로 붙여넣습니다. 실습 03의 등록 초안 검토 요청과 실습 02의 원문 재검토 요청을 추가했습니다. 승인 문장은 검토를 마친 뒤에만 사용합니다. 사이트에 붙여넣기만 하면 외부 작업이 수행되는 기능은 없습니다.

페이지 이동과 핸즈온 콘텐츠를 추가 검사하려면:

```sh
NODE_PATH=/tmp/neowiz-qa/node_modules node tests/navigation.cjs
NODE_PATH=/tmp/neowiz-qa/node_modules node tests/hands-on.cjs
NODE_PATH=/tmp/neowiz-qa/node_modules node tests/topic2.cjs
```

## 화면 구성

각 실습은 프롬프트 → 결과 확인 체크 → 다음 단계 순서로 읽습니다. 연결 실패·예상 결과·원문·수정 요청은 필요할 때 펼칩니다. 분 단위 진행 가이드는 강사용 모드에서 확인합니다. 프롬프트 비교 화면의 간단 요청·결과 지정·업무 위임 예시도 각각 복사할 수 있습니다. 승인 단계와 원문 검증 조건은 유지합니다.

## 메인과 웹 배포

메인에서 “발표자료 보기”는 제공된 [Canva 발표자료](https://canva.link/kzwovkavwfsv1v4)를 새 탭으로 엽니다. 로그인하지 않은 별도 브라우저에서 해당 디자인의 제목 `ai-enablement-101`과 조회 경로를 확인했습니다. 외부 Canva의 공유 정책이 바뀌면 교육 전 링크를 다시 확인하세요. 실습 화면은 상단 “교육 홈”으로 메인에 돌아옵니다.

```sh
python3 scripts/package-site.py
```

생성된 `dist/` 안의 네 파일을 정적 호스팅의 공개 디렉터리에 올리거나, `neowiz-ai-training.zip`을 풀어 동일하게 배치합니다. `dist` 폴더 자체를 올릴지 그 안의 파일을 올릴지는 호스팅의 배포 디렉터리 설정에 맞춥니다. 서버 측 코드·환경 변수·Google 자격 증명은 필요하지 않습니다. 루트 또는 하위 경로에 배포할 수 있도록 모든 내부 링크를 상대 경로로 구성했습니다.

```text
index.html
guide.html
assets/
  neowiz.png
  megazonecloud.svg
```

개발용 원본, QA, 테스트, 가상 메일 TXT와 미리보기 이미지는 웹 배포 ZIP에서 제외합니다. 기존 `index.html#search` 등의 공유 링크는 `guide.html#search`로 자동 연결합니다. 같은 HTTP 출처에서 메인/실습 페이지를 나눠도 기존 체크 저장 키를 유지합니다. 새 도메인으로 옮기면 기존 도메인의 브라우저 기록은 자동 이전되지 않습니다.

로컬에서 메인을 확인하려면 기존 서버의 `http://127.0.0.1:8080/index.html`을 엽니다. 메인과 로고는 오프라인에서도 표시되지만 Canva와 외부 AI/Google 작업에는 인터넷이 필요합니다.

```sh
NODE_PATH=/tmp/neowiz-qa/node_modules node tests/home.cjs
TRAINING_URL=http://127.0.0.1:8080/guide.html NODE_PATH=/tmp/neowiz-qa/node_modules node tests/navigation.cjs
```

로고는 AI로 재제작하거나 형태를 합성하지 않았습니다. 네오위즈는 [공식 IR 자료](https://cdn.neowiz.com/neowiz-site/assets/ir-library/3Q25_NWZ-IR-PPT_EN-itjp3znq.pdf)에 포함된 가로형 로고 이미지와 투명도 마스크를 추출했고, 메가존클라우드는 [공식 홈페이지](https://www.megazone.com/)의 검은색 헤더 SVG를 원형대로 저장했습니다. 공식 합작 사업·공동 주최 같은 별도 관계 문구는 추가하지 않았습니다.

GitHub Pages 공개 주소: https://issu-ai.github.io/neowiz/

게시 원본은 `main` 브랜치의 루트(`/`)입니다. 이후 변경을 `main`에 push하면 Pages가 자동으로 다시 배포합니다. `.nojekyll`로 HTML과 정적 자산을 그대로 게시합니다. 배포 상태는 저장소 Settings → Pages 또는 Actions에서 확인합니다.
